# 变更记录

## 0.0.2

状态：已通过 OWW211 验收。以下内容记录本版本的实现范围和验证结果。

- 目录页点左上标题可退出。
- 阅读页重写为连续窗口：向下追加下一页，向上插入上一页并补偿滚动偏移；新增 `readerWindow first/current/last/scroll` 状态用于设备验收。
- 页面变更使用异步 token 隔离，停止旧 fling，并在新布局完成后恢复滚动定位；翻到上一页定位页底，翻到下一页定位页顶。
- 操作页记录来源 `DIRECTORY`、`READER`、`EDITOR`：目录长按返回目录，阅读操作页返回原进度，编辑操作页返回草稿编辑。
- 目录文档行支持横滑；手势导航会取消子控件点击，同时保留按钮和滑块的触摸行为。
- 重命名后切换 reader 并迁移阅读进度。
- 编辑读取失败不进入空编辑器；保存采用原子写入，失败时保留草稿；保存完成后重建 reader。
- 页面挂载恢复淡入和轻微横向转场；挂载前重置旧视图状态，避免动画残留污染新页面。

后续修复和验收以当前源码、[维护回归清单](MAINTAINING.md)和设备测试记录为准。
