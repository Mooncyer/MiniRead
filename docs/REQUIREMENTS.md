# 需求基线

本文由原始产品设计整理而来，用于记录当前项目目标，而不是替代代码行为说明。实现状态以 README、架构文档和当前源码为准。

## 产品

- 中文名：笔记
- English name：MiniRead
- Application ID：`mini.read`
- 当前版本：`0.0.2`
- 目标设备：Android 手表，主要测试 OPPO Watch 3 Pro（OWW211）

## 核心范围

- 管理 `/storage/emulated/0/MiniRead/` 文档目录。
- 支持 `.txt` 和 `.md`。
- 支持系统文件打开方式和导入到应用目录。
- 支持大文本分页、断点续读、编辑、重命名、删除和新建。
- 默认深色主题，同时提供浅色主题和英文资源。
- 支持横滑导航和 OPPO Watch 表冠滚动。

## 平台约束

- 原生 Kotlin Android，不使用 H5 或 Electron。
- `minSdk 23`，`targetSdk 30`。
- ABI 为 `armeabi-v7a` 与 `arm64-v8a`。
- 关注手表 200dp 级别小屏、60Hz/高刷新率、低内存和低包体。

## 已确定的交互规则

- 阅读页和编辑页优先使用整屏内容。
- 普通页面和文档操作页的空白区域也必须支持横滑。
- 普通阅读：左向右返回，右向左进入操作页。
- 编辑模式：左向右保存并回目录，右向左进入编辑操作页。
- 编辑操作页：提供“退出编辑”和“换行”。
- 删除需要二次确认。

## 非目标

- 不支持富文本文件、PDF、EPUB 或图片书籍。
- 不把整个大文档一次性渲染到内存。
- 不把 `adb input roll` 视作真实表冠验收方法。
